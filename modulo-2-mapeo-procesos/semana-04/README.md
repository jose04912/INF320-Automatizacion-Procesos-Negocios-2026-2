# Semana 4 — Técnicas de Análisis de Procesos

**Módulo 2: Herramientas, diseño e implementación de procesos automatizados**

---

## Objetivos de aprendizaje

- Aplicar técnicas de levantamiento de información de procesos: entrevistas, observación directa y análisis de datos operativos.
- Analizar el proceso elegido por el equipo usando al menos dos de estas técnicas.

---

## Contenidos de la semana

### Teoría (martes)

1. Técnicas de análisis de procesos:
   - **Entrevistas** estructuradas y semiestructuradas al responsable del proceso
   - **Observación directa** (walkthroughs): seguir el proceso paso a paso en tiempo real
   - **Análisis de datos operativos**: tiempos de ciclo, volúmenes, tasas de error
2. Cómo diseñar un guion de entrevista efectivo
3. Indicadores operativos típicos en e-commerce: tiempo de procesamiento de pedido, tasa de abandono de carrito, tiempo de respuesta al cliente

### Práctica/Laboratorio (jueves)

Cada equipo aplica las técnicas a su proceso elegido:
- Realiza una entrevista simulada o real al "dueño del proceso"
- Documenta observaciones
- Estima datos operativos aproximados

El docente entrega una **guía de entrevista y plantilla de registro** que el equipo debe usar.

## Guía de preguntas para la entrevista de análisis de proceso

```
SOBRE EL PROCESO
1. ¿Puedes describir el proceso paso a paso desde que inicia hasta que termina?
2. ¿Quiénes intervienen en el proceso? (roles, sistemas, departamentos)
3. ¿Con qué frecuencia ocurre este proceso? (diario, semanal, por pedido)
4. ¿Cuánto tiempo toma desde el inicio hasta el fin en promedio?

SOBRE LOS PROBLEMAS
5. ¿Cuáles son los pasos que más tiempo consumen? ¿Por qué?
6. ¿En qué pasos se cometen errores con más frecuencia?
7. ¿Hay pasos que se hacen manualmente que podrían automatizarse?
8. ¿Alguna vez el proceso "se atasca"? ¿En qué punto?

SOBRE LOS DATOS
9. ¿Qué información se genera en cada paso? (formularios, emails, hojas de cálculo)
10. ¿Cómo se comunican los diferentes actores del proceso? (email, WhatsApp, sistema)
```
